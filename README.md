# 📌 To-Do CLI App

A fancy and fun command-line to-do list application built in Python by [@thekanhakodes](https://github.com/thekanhakodes). This app lets you manage your tasks right from the terminal with colorful outputs and intuitive options.

---

## 🚀 Features

- ✅ Add new tasks
- 📋 View all tasks
- ✔️ Mark tasks as done
- 🗑️ Delete tasks
- 🎨 Colorful and clean CLI interface (powered by `colorama`)
- 💾 Local JSON-based storage

---

## 🛠️ Installation

```bash
git clone https://github.com/thekanhakodes/todo-cli.git
cd todo-cli
python -m pip install -r requirements.txt
```

---

## ▶️ Usage

From the `todo-cli` repository root, run:

```bash
python main.py
```

The app reads and saves tasks in `tasks.json` in the current working directory.

Then follow the interactive menu:

```
📌 TO-DO CLI APP | by @thekanhakodes
----------------------------------------
1️⃣  Add Task
2️⃣  List Tasks
3️⃣  Mark Task as Done
4️⃣  Delete Task
5️⃣  Exit
----------------------------------------
```
